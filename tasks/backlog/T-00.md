## Goal
Stand up the Turborepo + pnpm workspace with `apps/{api,web,mobile,docs}`, `packages/{ui,
shared-types,api-client,prompts,testing}`, a root `justfile` (`just format|lint|typecheck|
test|dev`), and a minimal `.github/workflows/ci.yml` running the standard pipeline from
`standards/AGENTS.md` §Gating.
Links: design §8 row T-00; `ai_native_monorepo_architecture_blueprint.md` §Phase 1.

## Contract
- pnpm workspaces + `turbo.json` config; each app/package exposes `format/lint/typecheck/test`.
- CI gates: format → lint → typecheck → test → build, plus I3/I5 placeholder hooks.
- Nothing here owns a contract yet — that's T-01.

- [ ] `pnpm install` is clean and `just` exists + `just typecheck` runs on an empty tree.
- [ ] CI runs the pipeline and is green on an empty tree.

must still pass.
