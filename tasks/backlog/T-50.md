## Intent
Turn the seed plan `fullbody-periodized` into real, scheduled **regimen** behavior, and prove the
**slot-level `params`** mechanism that makes periodization work without per-week code.

## Scope
- [ ] **Flat 3+1:** `plan_week(0)` has 4 slots: `hiit-upper-30` · `hiit-lower-30` ·
   `hiit-full-body-30` · `stretch-reset-15` (`cycle_weeks = 1`; every week identical).
- [ ] `workout_plan` / `plan_week` / `plan_slot` tables + resolver
   `getPlanSession(planSlug, week, slot) → {template, params, beats, total}`).
- [ ] **Scaling via `buildTimeline(params)`** (`work_scale`/`rest_scale`/`rounds_mult`/
   `target_rpe_focus`) — prove the same template yields different durations per slot.
- [ ] Rotation + "today's slot" resolver by date.

demonstrably change the materialized run length; `rest` slot ⇒ null template. Docs: §3/§4/§6.
