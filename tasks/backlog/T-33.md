## Intent
MVP is **half-auth-free** (D9): *starting/watching* a workout needs no account, but a user needs
to **own their one SoundCloud playlist**. Provide the minimal surface for that.

## Scope
- [ ] `user` table + a **light session** (signed token or email→session; **not** a full auth system).
- [ ] `playlist` table — **one per user (`user_id UNIQUE`)**: `provider='soundcloud'`,
   `playlist_ref` (public URL / `/playlists/<id>`), `volume`, `start_on`, `is_default`.
- [ ] Endpoints (§6): `POST /me` · `GET/PUT/DELETE /me/playlist`.
   **Server-side validate** the SoundCloud URL (HEAD/oEmbed) so a bad URL never reaches the TV embed.
- A solo run attaches the user's one playlist; a room run attaches the host's; none ⇒ silence.

## Acceptance
pytest: create user, save/replace/delete one playlist (one-to-one enforced); URL validation
rejects a bogus URL; run attaches the correct `playlist_id`. Migration up/down. Docs: §4/§5/§6.

## STOPs / HALTS
- **STOP-A:** new public API surface (`/me*`) — design with a human.
- No secret in MVP (oEmbed is public) ⇒ no STOP-E. OAuth auto-pull is F-08.

## Definition of Done
`just` gate green; `total_seconds`/invariants unaffected; migration in CI; docs updated.

## Notes
Future multi-playlist = drop `user_id UNIQUE` + add a "primary" flag. F-08 adds OAuth on top.
