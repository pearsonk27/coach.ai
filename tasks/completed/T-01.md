## Goal
Author the canonical Zod schema (`shared-types/timeline.z.ts` + `catalog.z.ts`): `Beat`,
`WorkoutRun`, `WorkoutPhase`, `PhaseExercise`, catalog enums, `MusicRef`, and
`PlanSlot.params`. Mirror into Pydantic v2 in `apps/api`. Add a **drift snapshot test** (I3)
so the two can't diverge.
Links: design §2 D3, §4, §6.

## Contract
- `Beat` union: `phase-intro | prep | work | rest | cooldown-hold`, each `{id, kind, durationMs}`,

- `WorkoutPhase`, `PhaseExercise`, catalog enums, `MusicRef { provider, playlist_ref?, volume?, start_on? }`.
- `PlanSlot.params { work_scale?, rest_scale?, rounds_mult?, target_rpe_focus? }`.

### STOP-A report — the public contract
- **What shipped:** the canonical `shared-types` contract (Beat/WorkoutRun/phase/catalog/plan
     shapes + `MusicRef`/`PlanSlot.params`) and its Pydantic mirror, with a language-neutral
      snapshot + a runnable drift guard.
- **Why A:** this task **creates a public surface** that T-10 (schema), T-20 (`buildTimeline`),
      T-21 (clock), T-30/T-31 (API/OpenAPI/client) all import. Getting the **shape, the wire key
     mapping, and the Beat union wrong** would cascade into every downstream slice.
- **Risk:** downstream coupling. Concretely: (1) the JSON wire key set; (2) the snake⇄camel key
       mapping (frozen in `keyAliasByType`); (3) the `PhaseExercise.exercise` ⇄ runtime
     `Beat.exerciseRef` slug convention; (4) enum value sets (`RunStatus`/`RunSource`/`PhaseType`/…).
- **Reversibility:** cheap now — nothing depends on it yet; it is **free to change** before the
      first consumer lands. That is *why* sign-off is due here rather than at T-10/T-20.

### Decisions for sign-off (read these first)
1. **Wire format = camelCase JSON**, snake in Python (via `to_camel` alias). Enum *values* are
     literal shared strings; only *field names* are camelCased. Confirm this matches the eventual
      `api-client` codegen + client expectations.
2. **Bootstrap manifests are hand-synced** (zod/pydantic not yet installed). The guard treats the
     **snapshot as canonical** and asserts both manifests match it. **On T-10/T-31** (runtimes
      land, STOP-D addendum): regenerate `contract.fields.*.json` from `z.toJSONSchema` /
      `model_json_schema(by_alias=True)` and add those introspection layers (the guard already
     supports them; only the deps are missing).
3. **Beat.work carries `exerciseRef`** while `PhaseExercise` uses `exercise` — both are catalogue
      slugs (content-as-data, D3); T-20 `buildTimeline` maps phase items → beats by this key. The
      key rename is *named + intentional*, not drift (documented in the snapshot map + this note).
